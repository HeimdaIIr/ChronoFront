## Configuration RFID pour tests locaux

### Endpoint lecteurs RFID
```
POST http://IP_LOCAL:8000/api/raspberry
```

### Headers requis
```
Content-Type: application/json
Serial: NUMERO_SERIE_LECTEUR
```

### Format JSON
```json
[
  {"serial": "2000003", "timestamp": 743084027.091}
]
```

### Important
- ❌ **NE PAS utiliser 127.0.0.1** (localhost du lecteur lui-même)
- ✅ **Utiliser l'IP réseau du PC** (ex: 192.168.1.45)
- ✅ Laravel doit tourner avec `php artisan serve --host=0.0.0.0 --port=8000`
- ✅ Lecteur et PC sur même réseau WiFi
